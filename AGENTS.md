# Repository Agent Rules

Read `.chatgpt/PROJECT_CONTROL.md` before editing this repository.

- Confirm this repository and project identity before making changes.
- Do not bring in files, domains, analytics IDs, DNS settings, content, or requirements from another project.
- Inspect current files before editing.
- Make the smallest safe change.
- Preserve working behavior unless the requested task requires changing it.
- Do not say a production fix is complete until deployment and the relevant live URL have been checked.
- Verify unknown infrastructure facts instead of guessing.
- Check the affected behavior after each change.
- Use `.chatgpt/PROJECT_CONTROL.md` as the canonical scope and identity reference.
